# 🎲 Guia de Conversão: D&D 5e → Daggerheart

[[Inicio|🏠 Início]]

---

## Adversários

### CA → Evasão
A CA do D&D vira **Evasão** no Daggerheart. Valores típicos:

| D&D CA | DH Evasão |
|--------|-----------|
| 10–12 | 10–11 |
| 13–15 | 12–13 |
| 16–18 | 14–16 |
| 19–21 | 17–19 |
| 22+ | 20+ |

---

### HP → HP + Limiar Grave
O HP do D&D é reduzido e complementado com o **Limiar Grave** (dano single-hit que conta como ferida grave):

| D&D HP | DH HP | Limiar Grave |
|--------|--------|--------------|
| 10–25 | 4–6 | 6–8 |
| 26–50 | 7–10 | 9–12 |
| 51–80 | 11–16 | 12–15 |
| 81–120 | 17–22 | 14–18 |
| 121–170 | 22–28 | 16–20 |
| 171–230 | 28–36 | 18–22 |
| 230+ | 36–45 | 20–26 |

---

### Dano → Dano DH
O dano é reduzido levemente e os dados ajustados:

| D&D Dano | DH Dado |
|----------|---------|
| 1d4+2 | 1d4+1 |
| 1d6+2 | 1d6+2 |
| 1d8+3 | 1d8+2 |
| 2d6+3 | 1d8+3 ou 2d6+2 |
| 2d8+4 | 2d8+3 |
| 2d10+5 | 2d10+4 |
| 3d10+6 | 3d8+5 |

## Salvaguardas → Testes de CD

Em D&D, salvaguardas usam atributos específicos. Em DH, são testes normais com o atributo equivalente:

| D&D Salvaguarda | DH Equivalente |
|-----------------|----------------|
| Força (STR) | Força |
| Destreza (DEX) | Agilidade |
| Constituição (CON) | Vigor |
| Inteligência (INT) | Conhecimento |
| Sabedoria (WIS) | Instinto |
| Carisma (CHA) | Presença |

**CD de conversão:**

| D&D CD | DH CD |
|--------|-------|
| 10–11 | 10–11 |
| 12–13 | 11–12 |
| 14–15 | 12–13 |
| 16–17 | 14–15 |
| 18–19 | 15–16 |
| 20+ | 17+ |

## Habilidades Especiais

### Multiataques
Em D&D, muitos inimigos atacam múltiplas vezes. Em DH, isso vira:
- 2 ataques: um único ataque com dano levemente maior, OU dois ataques de custo de ação
- 3+ ataques: raramente — reserve para chefões

### Auras
Auras de D&D viram **Passivas de Área** em DH — sem custo de ação, mas geralmente geram 1 Medo por rodada para o GM.

### Resistências e Imunidades
Mantenha as imunidades temáticas importantes (fogo para elementais de fogo, etc.). Resistências menores podem ser ignoradas para simplificar.

### Feitiços de Chefões
Converta para **Habilidades Especiais** com custo de Medo (1–2 Pontos de Medo para ativar as mais poderosas).
