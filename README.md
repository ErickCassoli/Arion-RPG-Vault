# Arion — acervo de RPG no Obsidian

Vault de notas de RPG organizado em duas áreas: `Arion/` e `As Sombras de Luminares/`. A pasta `.obsidian/` guarda a configuração do Obsidian.

## Abrir

No Obsidian, escolha a opção de abrir uma pasta como vault e selecione a raiz deste repositório. Preserve a estrutura de pastas para manter os vínculos relativos das notas e dos anexos.

## Organização

| Pasta | Conteúdo |
|---|---|
| `Arion/` | Primeira área de notas |
| `As Sombras de Luminares/` | Segunda área de notas |
| `.obsidian/` | Configuração do vault |

O Git registra versões dos arquivos do vault. Sincronização do Git e sincronização própria do Obsidian são mecanismos diferentes; confira alterações locais antes de integrar versões vindas de outro dispositivo.

A manutenção deste README não alterou notas, anexos nem configurações do vault.
